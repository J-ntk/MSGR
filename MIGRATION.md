# Переезд mystudygr.com с WordPress на новый сайт

Цель: заменить WordPress на новый сайт **без потери позиций в Google** и с улучшением SEO.
Откат в любой момент — 1 минута (домен просто снова направляется на старую папку).

---

## Что мы знаем о текущем сайте (проверено 09.11.2026)

| | |
|---|---|
| Хостинг | **Beget** (аккаунт `djdordje`), Apache + PHP 8.2 |
| Движок | WordPress, тема Astra + Elementor 3.20 / Pro 3.11 (устарели), 17 плагинов, 14 без обновлений |
| Страницы в Google | `/`, `/about-us/`, `/learning/`, `/contacts/`, `/услуги/`, `/home/` (старый дубль главной) |
| Записей блога | 0 |
| Форма | Ninja Forms → `mystudygr1@gmail.com` + email админа, отправка через **smtp.beget.com** |
| Почта на домене | на Beget — **MX-записи и почту не трогаем** |
| Аналитика | GTM `GTM-MCM45RZH`; Google Analytics `G-406W8H07NW` загружается **внутри GTM** → продолжит работать |
| Search Console | подключён через плагин Site Kit → нужно добавить второй способ подтверждения (шаг 1.3) |
| SEO на старом сайте | нет meta-описаний, нет hreflang, нет FAQ-разметки, sitemap только встроенный WordPress |

## Почему позиции не упадут

1. **Все адреса страниц те же**: `/`, `/about-us/`, `/learning/`, `/contacts/`, `/услуги/`.
2. **301-редиректы** для всех остальных старых адресов уже в `.htaccess`:
   `/home/` и `/главная/` → `/`, `/privacy-policy/` → `/privacy/`, `/author/…` → `/about-us/`,
   `/elementor-hf/…`, `/feed/` → `/`, `/wp-sitemap*.xml` → `/sitemap.xml`, `/index.html` → папка.
   Служебные пути WordPress (`/wp-admin`, `/wp-content`, `/wp-login.php`…) отдают **410 Gone** — Google быстро их забудет.
3. **Заголовок главной сохранён**: «Учеба и высшее образование в Греции».
4. Один канонический адрес: `https://mystudygr.com` (без www, только https).

## Что станет лучше для Google

- meta-описания на всех страницах, Open Graph, канонические ссылки;
- 3 языка (RU / UA / KZ) с hreflang → новые запросы из Украины и Казахстана;
- новые страницы: Университеты, Вопросы (FAQ-разметка → расширенный сниппет), Календарь, Тест, Статьи;
- структурированные данные: EducationalOrganization, FAQPage, Article;
- статический HTML без WordPress → загрузка в разы быстрее (Core Web Vitals);
- sitemap.xml со всеми языками; блог, который можно пополнять из админ-панели.

## Этап 1. Доступы и согласование (вы + владелец)

- [ ] 1.1 Согласие владельца и дата переезда (будний вечер, ~30 минут).
- [ ] 1.2 Логин в панель **Beget** (cp.beget.com).
- [ ] 1.3 **Google Search Console**: убедиться, что у вас есть доступ «Владелец» к ресурсу mystudygr.com.
      Добавить второй способ подтверждения — **DNS-запись TXT** (Search Console → Настройки → Подтверждение
      владения → «Поставщик доменных имён»; запись добавить в Beget → DNS). Без этого после удаления Site Kit
      доступ может пропасть.
- [ ] 1.4 Доступ к **Google Tag Manager** (GTM-MCM45RZH) — проверить, что тег GA4 `G-406W8H07NW` там есть (есть) и настроен Consent Mode.
- [ ] 1.5 **Telegram-бот** для заявок (@BotFather) — токен и chat id.
- [ ] 1.6 **GitHub-токен** для админ-панели (README → «Admin panel», пункт 4).

## Этап 2. Подготовка на Beget (посетители ничего не замечают)

- [ ] 2.1 **Резервная копия WordPress**: Beget → «Резервное копирование» → скачать файлы сайта и базу данных.
      Дополнительно: phpMyAdmin → экспорт базы. Хранить минимум 3 месяца.
- [ ] 2.2 Beget → «Сайты» → **создать новый сайт** (папка, например `mystudygr-new/public_html`).
      Прикрепить к нему временный поддомен **new.mystudygr.com** и выпустить для него SSL (Beget → SSL, Let's Encrypt).
- [ ] 2.3 Beget → «FTP» → создать FTP-аккаунт, ограниченный папкой нового сайта.
- [ ] 2.4 GitHub → репозиторий MSGR → Settings → Secrets and variables → Actions:
      секреты `FTP_SERVER`, `FTP_USERNAME`, `FTP_PASSWORD`, переменная `FTP_DIR` (папка, оканчивается на `/`).
      Actions → «Build and deploy» → **Run workflow** → сайт загрузится в новую папку.
- [ ] 2.5 В файловом менеджере Beget создать `api/config.php` (по образцу `config.example.php`):
      Telegram, `mail_from` (ящик на домене), `admin_setup_key`, `github_token`.
      На время теста добавить `https://new.mystudygr.com` в `allowed_origins`.
- [ ] 2.6 Открыть `https://new.mystudygr.com/admin/` → создать свой аккаунт → очистить `admin_setup_key` → создать аккаунт владельца.

## Этап 4. День переезда (~5 минут простоя максимум)

- [ ] 4.1 Beget → «Сайты»: **открепить** mystudygr.com и www.mystudygr.com от старого сайта WordPress
      и **прикрепить** к новому сайту.
- [ ] 4.2 Beget → SSL: убедиться, что сертификат для mystudygr.com и www установлен на новом сайте (при необходимости выпустить заново).
- [ ] 4.3 Проверить: `https://mystudygr.com/`, `/услуги/`, `/home/` (→ 301 на `/`), форма → заявка пришла.
- [ ] 4.4 В `api/config.php` убрать `new.mystudygr.com` из `allowed_origins`; открепить поддомен new.

**Откат**, если что-то пошло не так: снова прикрепить домен к старому сайту WordPress (он остаётся нетронутым).

- [ ] Search Console → Проверка URL: главная, /услуги/, /about-us/, /learning/, /contacts/ → «Запросить индексирование».
- [ ] Google Analytics → «В реальном времени»: визиты идут.
